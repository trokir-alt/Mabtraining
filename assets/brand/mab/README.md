# МАБ — Международная Академия Бильярда

Пакет бренда приложения. Из него `scripts/build-brand.mjs` собирает знак,
горизонтальную компоновку для шапки, штамп водяного знака на сукне и иконку
приложения.

## Исходник

`source/mab-logo.png` — логотип как прислан: белый на прозрачном фоне,
1280 × 733 px. Пирамида из шести шаров (пять голубых `#72D0F7`, нижний правый
белый), вертикальная черта с разрывом, «МАБ» и подпись «Международная
Академия Бильярда».

## Как сделаны векторы

Ничего не перерисовано на глаз.

- **Шары** — окружности по замерам исходника: радиус 35,3 px, шаг по
  горизонтали 92,05, между рядами 82,25, вершина в (288,1; 257,9). Центры
  выровнены по этой сетке — в исходнике они гуляют на полпикселя.
- **Черта** — два прямоугольника 18 × 80 и 18 × 82 по замерам.
- **«МАБ» и подпись** — трассировка исходника (potrace, увеличение ×4,
  заливка `evenodd`). Наложение на исходник расходится на 2,3 % по альфе —
  это сглаживание краёв, контуры совпадают.

Координаты во всех файлах — пиксели исходника, поэтому варианты различаются
только рамкой `viewBox`.

## Комплект

- `logos/mab-full-white.svg` — знак, «МАБ» и подпись.
- `logos/mab-horizontal-white.svg` — знак и «МАБ», для шапки приложения.
- `logos/mab-sign.svg` — пирамида в цветах бренда; `mab-sign-white.svg` — белая.
- `watermarks/mab-stamp-white.svg` — штамп водяного знака: белый знак с «МАБ»
  по центру коробки 206 × 42, в которую разложена сетка на сукне. Высота знака —
  90 % коробки. Подпись в штамп не входит: на сукне она нечитаема.
- `fonts/` — Manrope и лицензия (шрифт интерфейса, к логотипу не относится).

Пересобрать векторы из нового исходника — задача на трассировку, не на
`build-brand.mjs`: он только читает готовые SVG.
